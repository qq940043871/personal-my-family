## 一、产品愿景

### 1.1 产品定位

一款专为3-9岁儿童设计的编程启蒙游戏产品，通过趣味游戏帮助孩子：
- 认识电脑基本操作（鼠标、键盘）
- 培养编程思维（顺序、循环、条件、变量）
- 建立逻辑思考能力
- 激发对科技的探索欲

### 1.2 核心价值

| 价值点 | 描述 |
|--------|------|
| 趣味性 | 游戏化学习，让孩子爱学 |
| 渐进性 | 3-6岁/6-9岁分龄设计 |
| 实践性 | 动手操作，而非被动观看 |
| 成就感 | 即时反馈，鼓励式成长 |

## 二、用户群体分析

### 2.1 目标用户

| 年龄段 | 认知特点 | 交互能力 | 推荐模块 |
|--------|----------|----------|----------|
| 3-4岁 | 色彩敏感、注意力短 | 简单点击 | 认识鼠标、色彩认知 |
| 4-5岁 | 精细动作发展 | 点击+拖拽 | 简单游戏、顺序思维 |
| 5-6岁 | 逻辑萌芽 | 基础键盘 | 键盘熟悉、简单编程 |
| 6-9岁 | 逻辑思维建立 | 独立操作 | 完整游戏、编程启蒙 |

### 2.2 家长痛点

- 孩子沉迷短视频，希望有教育意义的内容
- 不知道如何引导孩子接触编程
- 希望孩子赢在起跑线，但又不想给太大压力

## 四、游戏详细设计

## 4.1 游戏一：大鱼吃小鱼

### 4.1.1 游戏概述

| 项目 | 内容 |
|------|------|
| 游戏类型 | 休闲益智 |
| 操作方式 | 鼠标移动 + 点击 |
| 目标年龄 | 3-6岁 |
| 游戏时长 | 5-10分钟/局 |
| 核心玩法 | 鼠标控制大鱼，吃掉比自己小的鱼，躲避大鱼 |

### 4.1.2 故事背景

```
🌊 可爱的海底世界住着一条叫"泡泡"的小鱼。
🐠 泡泡的梦想是成为海底最厉害的小鱼！
🐟 它需要通过吃小鱼来长大，但是要小心大鲨鱼！
👶 让我们帮助泡泡，用鼠标控制它成长吧！
```

### 4.1.3 视觉设计

#### 画面风格

- 整体风格：卡通梦幻海底世界
- 色彩方案：高饱和度明亮配色，保护视力
- 背景：浅蓝色渐变海底，有水草、珊瑚、气泡动画

#### 角色设计

| 角色 | 名称 | 描述 | 颜色 |
|------|------|------|------|
| 主角 | 泡泡 | 玩家控制的小鱼 | 橙色渐变 |
| 食物 | 小鱼群 | 可以吃的小鱼 | 彩色（多种） |
| 敌人 | 大鲨鱼 | 需要躲避 | 深灰色+红色眼睛 |
| NPC | 海马博士 | 关卡引导 | 绿色 |

#### UI布局

```
┌─────────────────────────────────────┐
│ ⭐ 0    👶 关卡1    🔊音量    ⚙️设置  │  顶部状态栏
├─────────────────────────────────────┤
│                                     │
│           🐟 🐠 🐟                  │
│         🐟  🦈  🐟                  │
│              🐟                     │
│           [泡泡] ← 玩家             │
│                                     │
│           🌿  🪸  🌿                │  海底场景
│              .  .                  │
│              o  o  (气泡)           │
│                                     │
├─────────────────────────────────────┤
│    🐟 吃掉 3 条小鱼就能升级！       │  底部提示
└─────────────────────────────────────┘
```

### 4.1.4 关卡设计

#### 关卡1：认识鼠标

| 项目 | 内容 |
|------|------|
| 关卡名称 | 鼠标初体验 |
| 教学目标 | 认识鼠标指针、移动鼠标 |
| 开启条件 | 首次进入游戏 |
| 通关条件 | 移动鼠标碰到3条静止的小鱼 |

**玩法流程：**
1. 屏幕显示"用鼠标指挥泡泡移动吧！"
2. 鼠标指针变成小鱼形状
3. 移动鼠标控制泡泡移动
4. 碰到静止的小鱼 → 小鱼被吃掉 + 星星特效
5. 吃到3条 → 通关动画 + 获得"鼠标小达人"徽章

#### 关卡2：点击捕捉

| 项目 | 内容 |
|------|------|
| 关卡名称 | 点击抓捕 |
| 教学目标 | 练习鼠标点击 |
| 开启条件 | 关卡1通关 |
| 通关条件 | 10秒内点击捕捉5条游动的小鱼 |

**玩法流程：**
1. 屏幕提示"点击小鱼来捕捉！"
2. 小鱼在屏幕内游动（速度慢）
3. 点击小鱼 → 被捕捉 + 得分
4. 10秒内捕捉5条 → 通关
5. 超时 → 重新挑战

#### 关卡3：大鱼吃小鱼

| 项目 | 内容 |
|------|------|
| 关卡名称 | 大鱼吃小鱼 |
| 教学目标 | 判断大小、躲避危险 |
| 开启条件 | 关卡2通关 |
| 通关条件 | 吃到5条小鱼，躲避大鲨鱼 |

**玩法流程：**
1. 引入大鲨鱼角色
2. 大鲨鱼在屏幕上下游动
3. 泡泡碰到比自己大的鱼 → 受伤（生命-1）
4. 泡泡碰到比自己小的鱼 → 吃掉 + 成长
5. 吃到5条小鱼 → 通关
6. 生命归零 → 重新挑战

#### 关卡4-6：熟练操作

| 关卡 | 名称 | 特色 |
|------|------|------|
| 4 | 速度挑战 | 小鱼游动速度加快 |
| 5 | 智慧躲避 | 大鲨鱼走位更聪明 |
| 6 | 终极挑战 | 限时60秒，吃10条鱼 |

### 4.1.5 数值系统

| 参数 | 数值 |
|------|------|
| 初始生命 | 3颗心 |
| 吃到小鱼 | +1分，+10%体型 |
| 被大鱼碰到 | -1心，-20%体型 |
| 升级所需分数 | 5/15/30/50/80 |
| 满级体型 | 200%初始大小 |

### 4.1.6 音效设计

| 场景 | 音乐 | 音效 |
|------|------|------|
| 主界面 | 欢快海底主题（80BPM） | - |
| 游戏进行中 | 轻快背景乐（100BPM） | 气泡声、水流声 |
| 吃到小鱼 | - | "波波~"可爱音效 |
| 碰到大鱼 | - | "哎呀~"提示音 |
| 通关 | 胜利音乐 | 星星音效 |
| 失败 | 轻快鼓励 | "再来一次吧~" |

### 4.1.7 交互反馈

| 操作 | 反馈 |
|------|------|
| 鼠标移动 | 泡泡跟随鼠标方向游动，有0.1秒延迟模拟水流 |
| 点击小鱼 | 小鱼消失特效 + "+1"飘字 |
| 吃到食物 | 泡泡身体发光1秒 |
| 受伤 | 屏幕闪烁红色 + 泡泡抖动 |
| 通关 | 烟花特效 + 星星收集动画 |

## 4.2 游戏二：键盘小特工

### 4.2.1 游戏概述

| 项目 | 内容 |
|------|------|
| 游戏类型 | 键盘动作游戏 |
| 操作方式 | 键盘方向键/WASD |
| 目标年龄 | 5-9岁 |
| 游戏时长 | 5-15分钟/局 |
| 核心玩法 | 键盘控制角色移动，吃金币/水果，躲避障碍物 |

### 4.2.2 故事背景

```
🚀 键盘小特工"键键"需要收集散落在魔法森林里的金币！
⌨️ 森林里有各种魔法键盘障碍物...
🎯 让我们用键盘帮助键键完成任务吧！
👦 熟悉键盘后，我们就能开始真正的编程学习啦！
```

### 4.2.3 视觉设计

#### 画面风格

- 整体风格：可爱魔法森林
- 色彩方案：绿色主调，彩色点缀
- 背景：动态森林，有树叶飘落、萤火虫

#### 角色设计

| 角色 | 名称 | 描述 |
|------|------|------|
| 主角 | 键键 | 戴键盘头盔的小特工 |
| 收集物 | 金币/水果 | 得分道具 |
| 障碍 | 键盘按键 | 障碍物（QWERT...） |
| 敌人 | 大怪兽 | 需要躲避 |

#### 场景地图

```
┌─────────────────────────────────────┐
│ ⭐ 0    👶 关卡1    ⏱ 00:30   ⚙️  │
├─────────────────────────────────────┤
│  🍎    🍎    🍎    🍎    🍎        │
│                                     │
│  🍎    [键键]  🍎    🍎    🍎      │  ← 玩家位置
│                                     │
│  🔴    🔴    🔴    🔴    🔴        │  ← 障碍物（键盘按键）
│       Q    W    E    R    T        │
│                                     │
│  🍎    🍎    🍎    🍎    🍎        │
│            🏁 出口                   │
└─────────────────────────────────────┘
```

### 4.2.4 关卡设计

#### 关卡1：认识键盘

| 项目 | 内容 |
|------|------|
| 关卡名称 | 键盘初体验 |
| 教学目标 | 认识键盘方向键 |
| 开启条件 | 大鱼吃小鱼通关3关 |
| 通关条件 | 使用方向键移动到出口 |

**玩法流程：**
1. 屏幕显示键盘图，标注方向键位置
2. 提示"按方向键让键键移动"
3. 按下方向键 → 角色移动一格 + 按键特效
4. 到达出口 → 通关 + 认识4个方向键

#### 关卡2：水果收集

| 项目 | 内容 |
|------|------|
| 关卡名称 | 水果大丰收 |
| 教学目标 | 练习方向键操作熟练度 |
| 开启条件 | 关卡1通关 |
| 通关条件 | 60秒内收集10个水果 |

**玩法流程：**
1. 屏幕散落各种水果（苹果、香蕉、葡萄...）
2. 使用方向键移动收集
3. 每吃一个水果 +10分 + 音效
4. 60秒内收集10个 → 通关

#### 关卡3：躲避障碍

| 项目 | 内容 |
|------|------|
| 关卡名称 | 键盘大冒险 |
| 教学目标 | 快速反应、躲避障碍 |
| 开启条件 | 关卡2通关 |
| 通关条件 | 从起点到终点，躲避键盘按键障碍 |

**玩法流程：**
1. 地图上有随机移动的键盘按键障碍
2. 碰到障碍 → 回到起点
3. 到达终点 → 通关

#### 关卡4-6：进阶挑战

| 关卡 | 名称 | 特色 |
|------|------|------|
| 4 | 限时冲刺 | 30秒限时从起点到终点 |
| 5 | 连续跳跃 | 加入空格键跳过障碍 |
| 6 | 综合挑战 | 收集+躲避+限时三重挑战 |

### 4.2.5 数值系统

| 参数 | 数值 |
|------|------|
| 初始时间 | 60秒 |
| 吃到水果 | +10分/+1秒时间奖励 |
| 碰到障碍 | 回到起点/-5秒 |
| 通关基础分 | 100分 |
| 连击加成 | 连续吃5个水果×1.5倍 |

### 4.2.6 键盘教学设计

#### 按键教学流程

```
第1步：认识位置
┌─────────────────────────┐
│  ↑  (上)   ←  →  (左右)│
│  ↓  (下)                 │
│  [空格] 跳跃              │
└─────────────────────────┘

第2步：实操练习
- 每按一个键 → 屏幕显示对应按键动画
- 按对 → "叮~"成功音
- 按错 → "再试一次~"提示

第3步：组合操作
- 方向键+空格组合
- 引入WASD alternate方案
```

#### 键盘贴纸（实物奖励）

- 每通关3关，奖励一张键盘贴纸
- 贴纸内容：QWERTY键盘每个按键图案
- 贴在真实键盘上，理论与实践结合

### 4.2.7 音效设计

| 场景 | 音乐 | 音效 |
|------|------|------|
| 主界面 | 森林探险主题 | 鸟鸣、树叶沙沙 |
| 游戏进行中 | 轻快冒险音乐 | 脚步、收集音效 |
| 吃到水果 | - | "叮咚~" |
| 碰到障碍 | - | "哎呀~" + 键盘敲击声 |
