# 🎮 游戏一：大鱼吃小鱼

## 1. 游戏概述

### 1.1 核心概念

一款基于鼠标操作的休闲益智游戏，玩家控制一条名为"泡泡"的小鱼，通过吃掉更小的鱼来成长，同时躲避大鲨鱼的追击。

### 1.2 目标

- **年龄段**：3-6岁
- **操作方式**：鼠标移动 + 点击
- **单局时长**：5-10分钟
- **核心体验**：轻松有趣的海洋探索，建立"大鱼吃小鱼"的直觉判断

---

## 2. 视觉与艺术设计

### 2.1 整体风格

| 维度 | 设计 |
|------|------|
| 艺术风格 | 卡通梦幻，参考《海底小纵队》《小猪佩奇》 |
| 视角 | 2D横版俯视（Top-Down） |
| 色彩 | 高饱和度明亮色，保护视力为主 |
| 线条 | 圆润平滑，无尖锐边缘 |

### 2.2 配色方案

```
主色调：
- 海洋蓝：#4FC3F7 （背景基础）
- 珊瑚橙：#FF8A65 （主角泡泡）
- 海草绿：#81C784 （装饰元素）

辅助色：
- 沙滩黄：#FFE082 （金币/得分）
- 珊瑚粉：#F48FB1 （装饰）
- 深海蓝：#1A237E （远景）

警告色：
- 鲨鱼灰：#546E7A （敌人）
- 警示红：#EF5350 （危险/受伤）
```

### 2.3 角色设计

#### 主角：泡泡（🐟）

```
外观：
- 橙色渐变身体，圆润可爱
- 两只大眼睛占比大（卡通比例）
- 橙色渐变尾巴，会随着移动摆动
- 头顶有一个小泡泡装饰

动画：
- 空闲：尾巴轻轻摆动，眼睛眨动（3秒周期）
- 移动：身体倾斜，尾巴摆动加速
- 吃到鱼：身体短暂发光，身体变大
- 受伤：身体抖动，眼角出现泪花

大小设定：
- 初始大小：40×30px
- 每吃一条鱼：+10%大小
- 最大大小：80×60px（满级）
```

#### 可食用小鱼（🐟群）

```
类型与颜色：
- 小蓝鱼 #29B6F6 （最常见）
- 小黄鱼 #FFEE58 （常见）
- 小绿鱼 #66BB6A （较少）
- 小紫鱼 #AB47BC （稀有，分数×2）

大小：15-25px（随机）
游动方式：平滑曲线游动，有随机转向
行为：主动远离大鱼（玩家），被追时加速
```

#### 敌人：大鲨鱼（🦈）

```
外观：
- 深灰色身体，体型较大（150×80px）
- 红色眼睛，带有"反派"气质
- 锋利牙齿若隐若现

动画：
- 游动：身体轻微摆动，气势汹汹
- 追捕：加速，尾巴摆动频繁
- 进食：嘴巴张开动画

行为：
- 在屏幕上下游动巡逻
- 检测到玩家在前方时，会加速追赶
- 速度随关卡递增
```

#### NPC：海马博士（🦞）

```
外观：
- 绿色小巧身体，戴着博士眼镜
- 拿着魔法教杖（星星装饰）

功能：
- 关卡开始时的教学引导
- 失败时的鼓励动画
- 通关时的庆祝动画

位置：屏幕固定位置，不参与游戏
```

## 3. 关卡设计

### 3.1 关卡总览

| 关卡 | 名称 | 难度 | 目标用户 | 核心教学 |
|------|------|------|----------|----------|
| 1 | 鼠标初体验 | ⭐ | 3-4岁 | 鼠标移动 |
| 2 | 点击抓捕 | ⭐⭐ | 4-5岁 | 鼠标点击 |
| 3 | 大鱼吃小鱼 | ⭐⭐ | 4-5岁 | 大小判断 |
| 4 | 速度挑战 | ⭐⭐⭐ | 5-6岁 | 反应速度 |
| 5 | 智慧躲避 | ⭐⭐⭐⭐ | 5-6岁 | 策略躲避 |
| 6 | 终极挑战 | ⭐⭐⭐⭐⭐ | 6岁+ | 综合能力 |

### 3.2 关卡1：鼠标初体验

**教学目标**：认识鼠标指针，理解鼠标控制

**玩法设计**：
```
启动流程：
1. 海马博士出现："你好呀！我是海马博士~"
2. 博士："今天我们要认识一个新朋友——鼠标！"
3. 鼠标指针变成小鱼形状
4. 博士："试着移动鼠标，指挥我们的泡泡吧！"

游戏机制：
- 屏幕上散落3条静止的小鱼
- 移动鼠标控制泡泡移动
- 碰到小鱼 → 小鱼被"吃掉" + 星星特效
- 吃到3条 → 通关

交互设计：
- 首次移动鼠标：指针变为引导动画
- 首次吃到鱼：弹出"太棒了！"鼓励
- 通关：全屏星星雨 + "鼠标小达人"徽章

失败条件：无（纯教学关卡）
时间限制：无
```

### 3.3 关卡2：点击抓捕

**教学目标**：鼠标点击操作

**玩法设计**：
```
启动流程：
1. 博士："泡泡现在要学习新本领——点击捕捉！"
2. 博士："看到游动的小鱼了吗？点击它们！"

游戏机制：
- 5条小鱼在屏幕内随机游动（速度：慢）
- 点击小鱼 → 被捕捉 + 得分 + 消失特效
- 10秒内捕捉5条 → 通关
- 超时未完成 → 重新挑战

交互设计：
- 点击成功："波波~"音效 + "+1"飘字
- 点击失败（点到空处）：轻微"咦？"提示
- 首次捕捉：慢动作回放增强成就感
- 10秒倒计时在屏幕显示

失败条件：10秒内未捕捉5条
时间限制：10秒
难度递增：每通过1次，下一轮小鱼速度+5%
```

### 3.4 关卡3：大鱼吃小鱼

**教学目标**：大小判断、危险躲避

**玩法设计**：
```
启动流程：
1. 博士："海底里不仅有小鱼，还有大鲨鱼！"
2. 博士："大鱼吃小鱼，我们要吃比泡泡小的鱼！"
3. 博士："小心！碰到大鲨鱼会受伤的！"

游戏机制：
- 引入大鲨鱼（体型是泡泡的3倍）
- 大鲨鱼在屏幕上下游动巡逻
- 碰到比自己小的鱼：吃掉 + 成长
- 碰到比自己大的鱼：受伤 -1生命
- 吃到5条小鱼 → 通关

大小判断：
- 泡泡初始体型：40px
- 可吃的小鱼：15-25px
- 敌人鲨鱼：120px
- 泡泡成长到60px后，可以吃更小的鲨鱼（进阶）

交互设计：
- 准备碰撞时：目标生物边缘发光预警
- 吃到小鱼：泡泡变大动画 + "波波~"音效
- 碰到鲨鱼：屏幕红色闪烁 + "哎呀~"音效 + 生命-1
- 生命为0：泡泡变小回到初始 + "再来一次~"鼓励

失败条件：生命归零
初始生命：3颗心
```

### 3.5 关卡4：速度挑战

**教学目标**：快速反应能力

**玩法设计**：
```
差异点：
- 小鱼游动速度提升50%
- 鲨鱼速度提升30%
- 时间限制：30秒
- 通关条件：吃到8条鱼

新增元素：
- 随机出现"加速"道具（吃到后短时间无敌+移动加速）
```

### 3.6 关卡5：智慧躲避

**教学目标**：策略规划能力

**玩法设计**：
```
差异点：
- 鲨鱼会预判玩家走位
- 引入"障碍物"（岩石、渔网）：穿过会减速
- 新增"隐身"道具：5秒内鲨鱼看不到玩家

策略提示：
- 屏幕边缘提示哪里有危险
- 博士会在关键时刻给出提示（可选）
```

### 3.7 关卡6：终极挑战

**教学目标**：综合能力验证

**玩法设计**：
```
差异点：
- 限时60秒
- 需要吃到10条鱼
- 同时存在2条鲨鱼
- 引入"保护罩"道具（限时免疫伤害）
- 通关条件：60秒内吃到10条且生命>0

奖励：
- 首次通关：获得"海底小英雄"徽章
- 评价系统：根据剩余时间和生命计算星级（★/★★/★★★）
```

# ⌨️ 游戏二：键盘小特工

## 1. 游戏概述

### 1.1 核心概念

一款基于键盘操作的冒险收集游戏，玩家控制小特工"键键"在魔法森林中收集水果，躲避键盘障碍物，最终到达终点。

### 1.2 目标

- **年龄段**：5-9岁
- **操作方式**：方向键/WASD + 空格
- **单局时长**：5-15分钟
- **核心体验**：键盘操作肌肉记忆建立，方向感培养

---

## 2. 视觉与艺术设计

### 2.1 整体风格

| 维度 | 设计 |
|------|------|
| 艺术风格 | 可爱奇幻森林，参考《超级马里奥》2D |
| 视角 | 2D横版平视（Side-Scrolling） |
| 色彩 | 绿色主调，暖色点缀 |
| 线条 | 圆润卡通 |

### 2.2 配色方案

```
主色调：
- 森林绿：#81C784 （背景主色）
- 树干棕：#8D6E63 （地面/障碍）
- 天空蓝：#4FC3F7 （远景）

点缀色：
- 金币黄：#FFD54F （收集物）
- 宝石红：#EF5350 （危险）
- 魔法紫：#BA68C8 （特效）

任务色：
- 出口绿：#66BB6A （终点）
```

### 2.3 角色设计

#### 主角：键键（⌨️小特工）

```
外观：
- 蓝色小人，圆头+大眼
- 戴着键盘头盔（显示QWERTY图案）
- 背着小小工具包
- 背着"任务卡"

动画：
- 待机：呼吸动画，任务卡晃动
- 移动：脚步动画（类似跑步）
- 跳跃：拉伸动画
- 收集：跳跃欢呼
- 受伤：眼泪汪汪

大小：32×48px

操作反馈：
- 按方向键：对应方向箭头在头顶显示0.5秒
- 按对：按键"嗒"声 + 成功特效
- 按错：轻微"咦"提示 + 重新可按
```

#### 可收集物：水果（🍎🍌🍇🍊）

```
类型：
- 苹果🍎 10分 （常见）
- 香蕉🍌 15分 （中等）
- 葡萄🍇 20分 （较少）
- 橙子🍊 25分 （稀有）
- 金币⭐ 50分 （随机）

动画：
- 轻轻上下浮动
- 被收集时飞向UI栏
```

#### 障碍物：键盘按键（🔵按键）

```
外观：
- 彩色方块，显示单个字母（Q/W/E/R/T/Y...）
- 不同颜色区分不同行

行为：
- 随机移动（横版）
- 碰到玩家 → 玩家回到起点

移动模式：
- Level 4：直线移动
- Level 5：正弦曲线移动
- Level 6：随机变向
```

## 3. 关卡设计

### 3.1 关卡总览

| 关卡 | 名称 | 难度 | 目标用户 | 核心教学 |
|------|------|------|----------|----------|
| 1 | 键盘初体验 | ⭐ | 5-6岁 | 认识方向键 |
| 2 | 水果大丰收 | ⭐⭐ | 6-7岁 | 方向操作熟练 |
| 3 | 键盘大冒险 | ⭐⭐⭐ | 6-7岁 | 躲避障碍 |
| 4 | 限时冲刺 | ⭐⭐⭐⭐ | 7-8岁 | 速度操作 |
| 5 | 跳跃挑战 | ⭐⭐⭐⭐⭐ | 7-8岁 | 空格键+方向 |
| 6 | 综合挑战 | ⭐⭐⭐⭐⭐⭐ | 8-9岁 | 全面能力 |

### 3.2 关卡1：键盘初体验

**教学目标**：认识方向键位置

**玩法设计**：
```
启动：
1. 键键出现："你好！我是键盘小特工！"
2. 键键："今天我们要认识键盘大家庭！"
3. 屏幕显示大键盘图，方向键高亮

游戏机制：
- 屏幕显示简单路径（3格长）
- 玩家从起点出发
- 每按方向键 → 移动一格 + 按键动画
- 到达终点 → 通关

教学设计：
- 方向键按下时，屏幕上对应按键高亮
- 按对："嗒"成功音
- 按错/无操作：提示音"再试一次~"

键盘教学：
┌────────────────────┐
│    ↑ 上             │
│  ← →  左右          │
│    ↓ 下             │
│    [空格] 跳跃      │
└────────────────────┘
```

### 3.3 关卡2：水果大丰收

**教学目标**：方向操作熟练度

**玩法设计**：
```
游戏机制：
- 屏幕随机散落10个水果
- 60秒倒计时
- 收集水果得分
- 收集10个 → 通关

交互设计：
- 每吃一个水果：水果飞向UI "+10"
- 连续收集：连击提示"2连击！""3连击！"
- 接近终点10秒：倒计时加速提示

难度递增：
- 地图变大
- 水果间距增加
```

### 3.4 关卡3：键盘大冒险

**教学目标**：躲避障碍

**玩法设计**：
```
新增元素：
- 键盘按键障碍物（显示Q/W/E/R/T...）
- 障碍物在地图上随机移动
- 碰到障碍 → 回到起点

地图设计：
- 起点在左，终点在右
- 中间有3条障碍物移动的"通道"
- 需要观察后快速通过

策略提示：
- 障碍物移动有规律（前期慢速）
- 博士提示："观察障碍物的规律！"
```

### 3.5 关卡4：限时冲刺

**教学目标**：速度与准确性

**玩法设计**：
```
限制：
- 时间：30秒
- 目标：从起点到终点
- 不需要收集水果

难度：
- 障碍物速度提升50%
- 需要连续快速按键
- 中间不能停顿
```

### 3.6 关卡5：跳跃挑战

**教学目标**：空格键+方向组合操作

**玩法设计**：
```
新增操作：
- 空格键：跳跃（跨过矮障碍）
- 方向+空格：跳跃移动

新增障碍：
- 低矮障碍（可跳过的沟壑）
- 高障碍（必须绕行）

教学：
- 博士："按下空格，键键会跳起来！"
- 练习：在空地练习跳跃
- 应用：跳过沟壑到达终点
```

### 3.7 关卡6：综合挑战

**教学目标**：综合能力

**玩法设计**：
```
综合元素：
- 收集：10个水果
- 躲避：3种障碍物
- 跳跃：需要跳过坑
- 时间：90秒

评价系统：
- ⭐：完成任务
- ⭐⭐：60秒内完成
- ⭐⭐⭐：80秒内完成+剩余10秒以上

奖励：
- 首次三星：获得"键盘大师"徽章
- 可重复挑战刷高分
```

## 4. 键盘教学设计

### 4.1 教学路径

```
阶段1：认识位置（关卡1）
- 显示大键盘图
- 手指对应位置
- 按下高亮显示

阶段2：肌肉记忆（关卡2-3）
- 100+次按键练习
- 闭眼也能按对

阶段3：组合操作（关卡5）
- 方向+空格协调
- 时机判断

阶段4：盲打基础（关卡6）
- 不看键盘
- 凭感觉操作
```

### 4.2 键盘贴纸奖励

```
通关奖励：
- 通关3关：奖励"键盘贴纸套装"
- 内容：QWERTY每个按键的卡通贴纸
- 用途：贴在真实键盘上
- 目的：理论与实践结合
```
